### Integration Issues

**Issue A (Medium): CSS/GSAP Hero Redundancy**
CSS `hm-fadeUp` animations on `.h-badge`, `.h-hero h1`, `.h-hero-desc`, `.h-hero-actions` run simultaneously with GSAP HeroEntrance timeline. CSS Animations Level 1 spec means CSS overrides GSAP inline styles during the animation window. Net effect: hero entrance plays via CSS animation path, not the carefully choreographed GSAP timeline.
**Fix:** Remove `animation: hm-fadeUp` declarations from hero child selectors in `landing-home.css`.
**Affected:** SCROLL-02, TYPE-03, FOUND-04

**Issue B (Low): CSS/GSAP Metrics Redundancy**
CSS `hm-fadeUp` animation on `.h-metrics` completes before GSAP ScrollTrigger fires, potentially neutralizing the GSAP stagger effect on individual `.h-metric` items.
**Fix:** Remove `animation: hm-fadeUp` from `.h-metrics` in `landing-home.css`.
**Affected:** SCROLL-01, SCROLL-03
