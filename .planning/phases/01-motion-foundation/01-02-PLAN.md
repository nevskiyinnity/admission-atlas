3. Wrap each of the 9 animated sections with `<AnimatedSection>`. Each section's existing className goes on the AnimatedSection wrapper. The inner section element keeps its className too (AnimatedSection adds a wrapper div — the section's class stays on the section).

   **Wrapping strategy — two valid approaches, choose the simpler one:**

   Option A (preferred if sections have simple class names): Move the section className to AnimatedSection:
   ```tsx
   <AnimatedSection className="h-sect">
     <section id="services">
       {/* existing content unchanged */}
     </section>
   </AnimatedSection>
   ```

   Option B (if sections have complex attributes): Keep section as-is, wrap with bare AnimatedSection:
   ```tsx
   <AnimatedSection>
     <section className="h-sect" id="services">
       {/* existing content unchanged */}
     </section>
   </AnimatedSection>
   ```

   **Use Option B** — it's safer because it doesn't move any existing attributes. The CSS initial states target `.h-sect` which stays on the section element inside the AnimatedSection div.

   **Sections to wrap (all 9):**
