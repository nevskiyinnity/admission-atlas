**Step 2 -- Add gradient bleed pseudo-elements for standard sections:**

Insert a new CSS block after the `.h-sect` rule. Use `::before` on `.h-sect` for a soft radial gradient bleed that spans the gap between sections:

```css
/* ── Section gradient bleeds ── */
```
