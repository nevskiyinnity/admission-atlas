**MagneticButton** (`magnetic-button.tsx`):
Create a `'use client'` component that wraps children in a `<div>` with `display: inline-block`.

Implementation:
- Import `useRef` from React, `useGSAP` from `@gsap/react`, `gsap` from `./gsap-registration`
- Props: `{ children: React.ReactNode }`
- Create `wrapRef = useRef<HTMLDivElement>(null)`
- Inside `useGSAP(() => { ... }, { scope: wrapRef })`:
  - Create `gsap.matchMedia()` and add `'(hover: hover)'` condition (NOT prefers-reduced-motion — magnetic is pointer-dependent, not motion-dependent)
  - Inside the matchMedia callback:
    - Guard: `if (!el) return`
    - Create `xTo = gsap.quickTo(el, 'x', { duration: 0.6, ease: 'power3.out' })`
    - Create `yTo = gsap.quickTo(el, 'y', { duration: 0.6, ease: 'power3.out' })`
    - `RADIUS = 50` (activation radius in px)
    - `STRENGTH = 0.4` (40% of offset = subtle pull)
    - `mousemove` handler: compute dx/dy from element center via `getBoundingClientRect()`, compute distance, if `dist < RADIUS` call `xTo(dx * STRENGTH)` and `yTo(dy * STRENGTH)`
    - `mouseleave` handler: call `xTo(0)` and `yTo(0)` to reset
    - Attach listeners on `el` (the wrapper div), remove in cleanup return
- Render: `<div ref={wrapRef} style={{ display: 'inline-block' }}>{children}</div>`

**TiltCard** (`tilt-card.tsx`):
Create a `'use client'` component that wraps children, adding 3D rotation on mousemove + CSS custom properties for light sheen.

Implementation:
- Import `useRef` from React, `useGSAP` from `@gsap/react`, `gsap` from `./gsap-registration`
- Props: `{ children: React.ReactNode; className?: string }`
- Create `cardRef = useRef<HTMLDivElement>(null)`
- Inside `useGSAP(() => { ... }, { scope: cardRef })`:
  - Create `gsap.matchMedia()` and add `'(hover: hover)'` condition
  - Inside the matchMedia callback:
    - Guard: `if (!card) return`
    - `MAX_ROTATION = 4` (degrees — requirement says 4-5deg max, use conservative 4)
    - Set `gsap.set(card, { transformPerspective: 800 })` — GSAP's way to apply perspective on the element being rotated. This is IMPORTANT: use `transformPerspective` (GSAP property) NOT `perspective` (CSS property). `transformPerspective` applies `perspective()` inside the transform string of the element itself, which works correctly for single-element 3D rotation. This avoids needing a parent wrapper with CSS `perspective`.
    - `mousemove` handler:
      - Get `rect` via `getBoundingClientRect()`
      - Compute `xNorm = (e.clientX - rect.left) / rect.width - 0.5` (range: -0.5 to 0.5)
      - Compute `yNorm = (e.clientY - rect.top) / rect.height - 0.5`
      - `rotateY = gsap.utils.clamp(-MAX_ROTATION, MAX_ROTATION, xNorm * MAX_ROTATION * 2)`
      - `rotateX = gsap.utils.clamp(-MAX_ROTATION, MAX_ROTATION, -yNorm * MAX_ROTATION * 2)` (negative because moving mouse up = positive rotation)
      - Call `gsap.to(card, { rotationX: rotateX, rotationY: rotateY, duration: 0.4, ease: 'power2.out', overwrite: 'auto' })`
      - Set `card.style.setProperty('--sheen-x', \`${e.clientX - rect.left}px\`)`
      - Set `card.style.setProperty('--sheen-y', \`${e.clientY - rect.top}px\`)`
    - `mouseleave` handler:
      - Call `gsap.to(card, { rotationX: 0, rotationY: 0, duration: 0.6, ease: 'power3.out' })`
      - Call `card.style.removeProperty('--sheen-x')` and `card.style.removeProperty('--sheen-y')`
    - Attach `mousemove` and `mouseleave` on `card`, remove in cleanup return
- Render: `<div ref={cardRef} className={className}>{children}</div>`

IMPORTANT — The TiltCard wrapper div replaces the `<article>` element's direct parent role. The className prop allows passing through the grid/layout classes. However, the bento grid children are `<article>` elements with classes like `h-bento-card h-bento-wide`. The TiltCard wrapper goes AROUND each article, NOT replacing it. So the DOM becomes `<TiltCard><article className="h-bento-card h-bento-wide">...</article></TiltCard>`. Do NOT pass className to TiltCard in page.tsx — the article keeps its own classes. The TiltCard wrapper div is a transparent container with no styling of its own.

IMPORTANT — Do NOT use a `style` prop with `perspective` or `transformStyle` on the TiltCard wrapper div. The `transformPerspective` on the card element handles 3D internally through GSAP's transform string. A wrapper with CSS `perspective` would conflict with the existing GSAP transforms from AnimatedSection's entrance animations.
