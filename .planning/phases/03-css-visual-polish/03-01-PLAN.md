Currently `.h-sect-head` has `text-align: center; margin-bottom: 20px;`. Add `position: relative;` so SVG accents can be positioned absolutely within it.

**2. Add SVG elements to page.tsx section headings.** Add one diamond and one ring accent to 4 sections:

- **Services section** `.h-sect-head`: Add a diamond accent to the right of the heading and a ring accent to the lower left.
- **Process section** `.h-sect-head`: Add a ring accent to the upper right.
- **Pricing section** `.h-sect-head`: Add a diamond accent to the left.
- **FAQ section** `.h-sect-head`: Add a ring accent to the right.

Each SVG element should:
- Have `aria-hidden="true"` (purely decorative)
- Use the class `h-accent` plus a variant class (`h-accent--diamond` or `h-accent--ring`)
- Use a unique positioning class or inline style for each placement (e.g. `h-accent--tr` for top-right, `h-accent--bl` for bottom-left)

**Diamond SVG markup:**
```tsx
<svg className="h-accent h-accent--diamond h-accent--{position}" viewBox="0 0 24 24" aria-hidden="true">
  <rect x="6" y="6" width="12" height="12" transform="rotate(45 12 12)" fill="none" stroke="currentColor" strokeWidth="1"/>
</svg>
```

**Ring SVG markup:**
```tsx
<svg className="h-accent h-accent--ring h-accent--{position}" viewBox="0 0 32 32" aria-hidden="true">
  <circle cx="16" cy="16" r="12" fill="none" stroke="currentColor" strokeWidth="1"/>
</svg>
```

**3. Add CSS styles for SVG accents** in landing-home.css (in the SECTIONS area):

Base accent styles:
```css
.landing-scope .shell .h-accent {
  position: absolute;
  color: var(--hm-gold);
  opacity: 0.10;
  pointer-events: none;
}

.landing-scope .shell .h-accent--diamond {
  width: 20px;
  height: 20px;
  animation: hm-spin-slow 35s linear infinite;
}

.landing-scope .shell .h-accent--ring {
  width: 28px;
  height: 28px;
  animation: hm-pulse-ring 6s ease-in-out infinite alternate;
}
```

Position variants:
```css
.landing-scope .shell .h-accent--tr { top: -6px; right: -36px; }
.landing-scope .shell .h-accent--bl { bottom: -8px; left: -32px; }
.landing-scope .shell .h-accent--tl { top: -6px; left: -36px; }
.landing-scope .shell .h-accent--br { bottom: -8px; right: -32px; }
```

**4. Add keyframe animations** (in ANIMATIONS section):

